# Releasing

How a version of Emberwit gets from `main` to the stores.

## One time setup (publisher)

| Item | Where it lives | Notes |
|---|---|---|
| Android upload keystore | `~/.emberwit-release/upload.jks` + `key.properties` (local), Codemagic group `emberwit_android` (CI) | Create with `keytool -genkeypair -v -keystore upload.jks -keyalg RSA -keysize 4096 -validity 10000 -alias upload`. Enroll in Play App Signing. |
| Play service account | `PLAY_JSON_KEY_PATH` (local), `PLAY_SERVICE_ACCOUNT_JSON` (CI) | Release manager permission on the app only. |
| Apple distribution certificate and profile | fastlane match repo (`MATCH_GIT_URL`) or Codemagic automatic signing | Bundle id `app.emberwit`. |
| App Store Connect API key | `APP_STORE_CONNECT_*` (local), integration `emberwit_asc` (CI) | App Manager role. |
| Production catalog signing key | Offline machine and a safe | See SECURITY.md release checklist. Never in CI. |
| Privacy policy page | `https://emberwit.app/privacy` | Publish `docs/PRIVACY_POLICY.md`. |

## Every release

1. Merge the release-please PR. It bumps `pubspec.yaml`, writes
   `CHANGELOG.md` and tags `vX.Y.Z`.
2. Update `fastlane/metadata/android/*/changelogs/<versionCode>.txt` and
   `fastlane/metadata/ios/en-US/release_notes.txt` (English and Bengali).
3. The tag triggers Codemagic: `android-release` (bundle to the Play internal
   track as a draft, after `STRICT=1 tool/security_audit.sh`) and
   `ios-release` (TestFlight). Locally the same is
   `cd fastlane && bundle exec fastlane android internal` / `ios beta`.
4. Run the device matrix (`docs/DEVICE_MATRIX.md`) on the internal build.
5. Promote in the Play Console / submit for App Review.
6. Archive `build/symbols/` and `mapping.txt` from the build artifacts.

## Store assets

| Asset | Source |
|---|---|
| Launcher icons, splash, launch image | `python3 tool/branding/generate_icons.py` |
| Play icon 512 and feature graphic 1024x500 | `docs/store/graphics/` (generated by the same script) |
| Listing text, en-US and bn-BD | `fastlane/metadata/android/`; App Store `fastlane/metadata/ios/en-US/` |
| Screenshots | Take on a real phone after onboarding with a model installed: chat (en, bn), models, device check, settings. Not committed yet. |
| Data safety / App Privacy answers | `docs/store/DATA_SAFETY.md` |

The iOS listing ships in English. If App Store Connect offers Bengali for
the listing, copy the Android bn-BD texts into
`fastlane/metadata/ios/<that locale>/`. The app itself is fully localized
either way.
